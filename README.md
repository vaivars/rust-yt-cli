# docs

This branch is the GitHub Pages site of `yt`, served at https://vaivars.github.io/rust-yt-cli/.

- `oauth-client.json` is `yt`'s OAuth client ID metadata document (CIMD). Its URL is `yt`'s client ID on every YouTrack instance that allows automatic OAuth client registration, so the file must never move or be renamed. Its contents may change.
- `.nojekyll` makes Pages serve the files as they are.

Changes reach this branch through squash-merged pull requests.
